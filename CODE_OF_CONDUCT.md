# Code of Conduct

This project adopts the [Contributor Covenant v2.1][cc] as its Code of Conduct.
The full text is published at:

  <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project — opening issues, submitting pull requests,
reviewing contributions, or interacting in any other community space — you
agree to uphold the standards described there.

## Reporting

To report a concern, contact the project maintainer privately:

- Email: `jacques.bourque@gmail.com`
  (subject prefix: `[conduct] DevBitsLab.Mcp.SourceGraph`)

Reports will be handled confidentially. Maintainers commit to acknowledging a
report within 5 business days and to acting on substantiated reports per the
enforcement guidelines linked above.

## Scope

This Code of Conduct applies in all project spaces — the GitHub repository,
issue tracker, pull requests, and any official communication channels — and
also applies when an individual is officially representing the project in
public spaces.

[cc]: https://www.contributor-covenant.org/
