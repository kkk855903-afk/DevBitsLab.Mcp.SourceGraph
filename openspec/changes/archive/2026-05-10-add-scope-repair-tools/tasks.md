## 2. Embeddings prune helper (storage support for `repair_scope minimal`)

- [x] 2.1 Add `Task<int> PruneOrphanedAsync(CancellationToken ct = default)` to `IEmbeddingsStore`. Returns the number of rows deleted. Implementation: `DELETE FROM symbol_embeddings WHERE rowid NOT IN (SELECT id FROM symbols)`. _Filter is `symbol_id NOT IN ...` rather than `rowid NOT IN ...` — vec0's primary key is the `symbol_id` column, not the synthetic rowid; matching by symbol_id is the correct invariant. Also prunes `embedding_meta` (the per-symbol model_version + content_hash bookkeeping table) so re-embedding after later symbol resurrection doesn't see stale meta. `DisabledEmbeddingsStore.PruneOrphanedAsync` returns `0`._
